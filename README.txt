ApV播放器 - 全文件复查 / 性能减负测试版

基线：已确认歌词显示正常、关闭播放器后歌词继续播放的版本。

本版针对整文件复查发现的渲染与实例生命周期问题做减负，不重写歌词内容逻辑：
1. 播放器根宿主保持 1×1px，不再覆盖整个视口；ball/panel 通过 overflow:visible 定位。
2. 悬浮球/播放器取消 backdrop-filter，避免 WebView/Tauri 实时背景采样。
3. 悬浮球隐藏且播放器关闭时，播放器根节点直接退出渲染树。
4. 三行歌词切换只更新上一行/当前行附近节点，不再遍历整首歌词 DOM。
5. 修复反复运行脚本时旧独立歌词宿主残留的问题。
6. 增加实例级 cleanup：重新运行脚本会清理旧 audio、pagehide、计时器、歌词宿主和菜单入口，避免多实例叠加。
7. 保留原有歌词解析、四种歌词模式、歌词动画、歌词位置与关闭播放器后继续显示逻辑。
